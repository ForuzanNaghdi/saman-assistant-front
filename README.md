# فرانت‌اند دستیار سامان

رابط کاربری چت فارسی (RTL) برای سرویس `customer-assistant-core`، ساخته‌شده با
React 18، TypeScript و Vite.

قابلیت‌ها:

- فهرست گفتگوها، انتخاب، حذف و شروع گفتگوی جدید
- پرسش و پاسخ با پاسخ استریم‌شده (SSE) و نمایش منابع بازیابی‌شده
- نمایش و ویرایش شناسهٔ کاربر که با هر درخواست در هدر هویت ارسال می‌شود
- نمایش آمادگی سرویس، پیام‌های خطای فارسی و پیگیری پاسخ‌های در انتظار


## اجرا در محیط توسعه

```bash
npm install
cp .env.example .env   # اختیاری؛ پیش‌فرض‌ها برای بک‌اند محلی کافی است
npm run dev
```

بررسی نوع‌ها و ساخت بستهٔ تولید:

```bash
npm run typecheck
npm run build      # خروجی در dist/
npm run preview    # پیش‌نمایش خروجی تولید
```

## استقرار

ایمیج Docker یک nginx است که فایل‌های `dist/` را سرو می‌کند و مسیرهای
`/api/*` (و همچنین `/chat`، `/ingestion` و `/health`) را با هدرِ گیت‌وی به API
فوروارد می‌کند؛ مرورگر درخواست‌ها را زیر `/api` می‌سازد تا از قاعدهٔ اینگرس
عبور نکند. `API_UPSTREAM` و `SAMAN_IDENTITY_SHARED_SECRET` در زمان اجرا خوانده
می‌شوند.
جزئیات، متغیرها و روش دیدن لاگ در Argo: [`docs/deployment.md`](docs/deployment.md).
